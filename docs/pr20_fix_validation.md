# PR #20 修正・確認記録

## 修正

- 弱いキック後、球が口元に止まったときに捕球・再キックの禁止を解除する。
  発射待ち中と、まだ球が機体から離れている間は解除しない。キッカー再充電は別途守る。
- Sumatra の合成加速度 3500 / 減速度 6000 mm/s² を全方向で適用する。
  反転・方向変更の最小速度点で刻み時間を分割する。新設定がない RAVEN は軸別制限を維持する。
- ダイレクトキックは直近の接近中の速度を使う。衝突をまたぐ急減した差分は除外する。
  古い最大入射速度を選んでキックを強くする処理を取り除いた。
- 受動反発は反転をまたぐ差分の後の最初の完全な出射区間から測る。
  能動キックの変化検出も、設定された床の減速を閾値に含める。direct の待機は物理時刻を使用する。

## 確認結果

- ビルド成功。CTest 2件成功（移動・接触判定、測定処理）。
- Sumatra: 青・黄とも前進・横・45度の加速 3492〜3504、減速 5985〜6010 mm/s²、最高速度約4000 mm/s。
- Sumatra と RAVEN: 青・黄とも 0.1 m/s のキック後に 2 m/s で再発射できた。
  RAVEN は初期の捕球動作から停止するまで物理時刻で待って測定する。
- 通常の 2 m/s キックは両設定・両チームで吸い戻しなし。
- Sumatra の置き直しによる連続キックは青・黄それぞれ8/8発。
- 停止した青の機体への 2速度 × 2角度（0°/30°）のダイレクトキックは、両設定とも4/4発。
  測定初速と式の予測の差は表示精度0.001%以内。
- 同じ4条件の受動反発中央値: Sumatra 0.552、RAVEN 0.806。材質の係数は変更していない。
- 設定生成の値が同梱 Sumatra 設定と一致することを確認。
